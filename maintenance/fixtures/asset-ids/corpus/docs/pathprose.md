# Paths that do not define an id

See `Server/Item/Items/Weapon/Sword_Prose.json` for the layout of a sword.

This line says nothing about files.

```json
{ "ItemId": "Sword_Prose" }
```

`Server/Item/Items/Weapon/Sword_Java.json`

```java
String s = "an unrelated snippet";
```

Nor does the line before a java fence, whatever it names.

```json
{ "ItemId": "Sword_Java" }
```
