# AUDIT METHOD — do not repeat the 2026-09-03 mistake. That audit inspected the
# classes the check's own regex matched and concluded from those two strings
# that the page had no Java surface. It was wrong on three of four pages: the
# regex requires a fully-qualified name ending in a capitalized segment, so it
# never sees a "**Package:**" line (lowercase tail), a bare interface name, or a
# method in a ```java fence or a table cell. universe-saves.md scored 2 on the
# heuristic while carrying 7 package sections and 10 java fences. Audit the
# PAGE, not the regex's matches: count "**Package:**" headings, ```java fences
# and "| Method |" tables before adding an entry here.
#
# A non-zero "**Package:**" count does NOT by itself disqualify an entry, but it
# raises the bar: the entry must say why that heading is a provenance citation
# (naming the class that implements a documented JSON "Type") rather than the
# start of an API section. The test is what follows it — a package line above a
# JSON property table and JSON examples is a citation; one above signatures, a
# method table or a ```java fence is an API section, and the page should be
# retagged instead.
#
