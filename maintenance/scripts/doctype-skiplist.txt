# Calibration skip-list for the doc-type/Java-reference consistency check in
# verify-docs.sh.
#
# The check flags a doc not tagged "Java API" that names >= 2 distinct
# com.hypixel.* classes, on the theory that it is mis-tagged. An entry here
# asserts the opposite: the page's class references are citations (the codec
# behind a documented JSON key) and the page documents no Java API surface of
# its own, so its non-Java tag is correct.
#
# Format: doc.md  # justification.
#
# WHAT THE CHECK NOW UNDERSTANDS (2026-09-04). The check excludes a class cited
# on a "**Package:**" line whose section carries POSITIVE evidence of being JSON
# documentation (a ```json fence or a Property/Key/Field table) and no Java
# surface (no ```java fence, no "| Method" table) — and only when every
# occurrence of that class on the page is such a citation. It reports how many
# citations it excluded, on how many pages, so a rule that silently stops firing
# is visible as a zero rather than as a pass. That is the audit method below,
# encoded.
#
# SO THIS LIST IS NOW THE RESIDUAL: citations the rule cannot classify, because
# they sit in prose or in a fence rather than on a "**Package:**" line. It is no
# longer where routine JSON-documents-a-Type pages go; those need no entry.
#
# AUDIT METHOD — unchanged, and still required before adding an entry. Do not
# repeat the 2026-09-03 mistake: that audit inspected the classes the check's own
# regex matched and concluded from those two strings that the page had no Java
# surface. It was wrong on three of four pages, because a regex requiring a
# fully-qualified name ending in a capitalized segment never sees a bare
# interface name or a method in a ```java fence or a table cell.
# universe-saves.md scored 2 on the heuristic while carrying 7 package sections
# and 10 java fences. Audit the PAGE, not the regex's matches: count
# "**Package:**" headings, ```java fences and "| Method |" tables.
#
# The retag test still governs: a package line above a JSON property table is a
# citation; a package line above signatures, a method table or a java fence is an
# API section, and the page should be retagged rather than skipped.
#
# A non-zero "**Package:**" count does NOT by itself disqualify an entry, but it
# raises the bar: the entry must say why that heading is a provenance citation
# (naming the class that implements a documented JSON "Type") rather than the
# start of an API section. The test is what follows it — a package line above a
# JSON property table and JSON examples is a citation; one above signatures, a
# method table or a ```java fence is an API section, and the page should be
# retagged instead.
#
